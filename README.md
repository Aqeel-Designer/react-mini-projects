# React Mini Projects

A collection of small React applications built to practice React fundamentals, component development, state management, and user interactions.

## Projects

- **Digital Clock** — Displays the current time and date.
- **Stopwatch** — Tracks elapsed time with start, stop, and reset functionality.
- **To-do List** — Manages tasks and practices state updates and data persistence.

## Technologies

- React
- JavaScript
- HTML5
- CSS3
- Vite

Each project is maintained in its own folder and can be run independently.

## Getting Started

Navigate into the project folder you want to run, install its dependencies, and start the development server:

```bash
npm install
npm run dev
```
